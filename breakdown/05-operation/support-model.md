# Support Model
<!-- Layer: 05-operation -->
<!-- Stable ID: OPS-SUPPORT-001 -->

## Description

This artifact documents support expectations for SSP4SIM consumers.

## Policy

No formal support model. SSP4SIM is an experimental/single-developer project.

## Issue Tracking

- All issues tracked via GitHub Issues
- Bug reports should include: minimal reproduction case, config file, log output, SSP archive path
- Feature requests, bug reports, and questions — all tracked as GitHub Issues

## Contribution

- Pull requests welcome
- Follow conventions in `docs/development.md`
- Include tests with changes
- See contributing section in `readme.md`

## Expectations

- No SLAs or response time commitments
- Best-effort maintainer response
- Community contributions are encouraged

## Traceability

- Backward: Intent constraints (experimental, not production-grade).
- Sources: `readme.md`, `docs/development.md`.
