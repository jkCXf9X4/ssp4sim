# IMP-016: Canonicalize Project Purpose Statement To PBS Intent Layer

## Status

Proposed

## Layer

00-intent

## Theme

The same project purpose sentence appears verbatim in `readme.md`, `product-breakdown/00-intent/purpose.md`, and `docs/overview.md`. Consolidate to the PBS intent layer as canonical and cross-link from the others.

## Evidence

1. `product-breakdown/00-intent/purpose.md`, line 11: "SSP4SIM is a C++23 library and application for simulating SSP (System Structure and Parameterization) archives. The goal is to provide a small experimental simulation engine for developing and testing simulation strategies."
2. `readme.md`, lines 5-7: "SSP4SIM is a C++23 library and application for simulating Structure and Parameterization (SSP) archives. The goal is to provide a small experimental simulation engine for developing and testing simulation strategies."
3. `docs/overview.md`, lines 5-7: Similar but slightly abbreviated — references the same positioning.

The parenthetical varies ("System Structure and Parameterization" vs "Structure and Parameterization") but the core sentence is identical.

## Current Pain Or Risk

- **Trivial drift**: If the project scope changes (e.g., becomes an engine for production use), the purpose statement diverges across files.
- **No canonical anchor**: The PBS intent layer exists precisely to own the "why" — but the readme and overview both reproduce it.

## Proposed Improvement

1. Keep the canonical statement in `product-breakdown/00-intent/purpose.md`.
2. In `readme.md`, replace lines 5-7 with a concise tagline and a link: "SSP4SIM is a C++23 simulation engine for SSP archives. See [product-breakdown/00-intent/purpose.md](product-breakdown/00-intent/purpose.md) for the full project purpose."
3. In `docs/overview.md`, replace the verbose purpose paragraph with a link to `product-breakdown/00-intent/purpose.md`.

## Expected Benefit

- Single canonical "why" document.
- readme.md becomes a true entry point (quick start + navigation) rather than a mission statement.
- docs/overview.md can focus on feature summaries with the purpose link for deeper context.

- **Risk**: Low. Text changes only.
