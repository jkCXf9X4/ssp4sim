# REQ-001: SSP 1.0 Archive Loading
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-001 -->

## Description

The engine MUST load and parse SSP 1.0 archives and unpacked SSP directories.

## Rationale

SSP 1.0 is the standard format for packaging co-simulation setups. Supporting both archive (.ssp zip) and unpacked directory formats enables flexible workflows.

## Acceptance Criteria

- Engine loads .ssp archive files
- Engine loads unpacked SSP directories
- Engine parses SSD XML, SSV/SSM parameter files
- Engine locates and references FMU binaries within the SSP
