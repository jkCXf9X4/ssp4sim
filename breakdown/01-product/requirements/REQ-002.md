# REQ-002: FMI 2.0 Co-Simulation Model Lifecycle
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-002 -->

## Description

The engine MUST instantiate, step, and terminate FMI 2.0 co-simulation FMUs through the complete lifecycle.

## Rationale

FMI 2.0 co-simulation is the core simulation capability. The lifecycle includes loading, instantiation, initialization, stepping, and cleanup.

## Acceptance Criteria

- FMU model description XML is parsed
- FMU shared library is loaded via dlopen (fmi4c adapter)
- FMI 2.0 lifecycle (instantiate → init → step → terminate → free) executes correctly
- Step failures result in proper cleanup without calling fmi2Terminate
