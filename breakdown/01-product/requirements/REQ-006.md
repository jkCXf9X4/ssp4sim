# REQ-006: User-Configurable Local Logging Levels and Sinks
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-006 -->

## Description

The engine MUST provide configurable local logging with multiple levels and sink types.

## Rationale

Different use cases require different logging verbosity and output destinations. Development needs detailed tracing; production needs minimal logging; operators need a clear separation between overview logs, archival logs, and live navigation logs.

## Acceptance Criteria

- Log level is configurable per sink (terminal, file, JSON, cutelog)
- Available levels: TRACE_L2, TRACE_L1, DEBUG, INFO, WARNING, ERROR, CRITICAL
- Hot-path logging can be compiled out with SSP4SIM_LOG_HOT_PATH=OFF
- Log sinks operate concurrently
