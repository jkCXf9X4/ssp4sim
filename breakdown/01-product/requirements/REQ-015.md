# REQ-015: SSP Parameter and Start-Value Application
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-015 -->

## Description

The engine MUST apply the SSP's parameterization to the simulation: parse system/component parameter bindings from SSV/SSM files or inline values, and apply parameter and connector start values (including FMU `<start>` attributes) to the FMUs before initialization.

## Rationale

An SSP archive carries a specific scenario's parameter values. Reproducible, correct runs depend on these values actually reaching the FMU connectors at init — otherwise the simulation does not reflect the archived scenario.

## Acceptance Criteria

- Parameter bindings (`.ssv` values, `.ssm` mappings, or inline) are parsed and resolved per the SSP standard
- Parameter values are matched to connectors via post-order traversal and dotted-path suffix matching
- Connector start values from the FMU model description contribute initial values
- Applied start values are written to parameters and inputs at initialization (and logged to the start-values artifact)
