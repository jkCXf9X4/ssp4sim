# REQ-011: Realtime Wall-Clock Pacing
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-011 -->

## Description

The engine MUST support pacing simulation execution to wall-clock time through the `simulation.realtime` configuration flag, so that simulation time advances in sync with real time.

## Rationale

Operator-facing runs, demonstrations, and hardware-in-the-loop contexts benefit from simulation time tracking wall-clock time. This is pacing only, not a hard real-time guarantee.

## Acceptance Criteria

- `simulation.realtime=true` paces each timestep with a wall-clock reference using `sleep_until`
- `simulation.realtime` defaults to `false`, running as fast as possible
- Pacing affects only timing, not simulation results

## Constraints

Realtime pacing provides no hard real-time guarantee; see the out-of-scope entry for real-time simulation guarantees in `scope.md`.
