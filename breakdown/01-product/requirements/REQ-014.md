# REQ-014: Configurable Output Paths with Timestamped Artifacts
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-014 -->

## Description

The engine MUST anchor default output artifact locations to the configured working directory and MUST support the `[TIME]` substitution in output path strings (CSV, SQLite, and log files), replacing it with the current timestamp at configuration load.

## Rationale

Users run repeated or concurrent simulations and need each run's artifacts to land in predictable, non-clobbering locations. Timestamped paths and per-run auto-named SQLite files provide distinct artifacts per run without manual renaming.

## Acceptance Criteria

- `simulation.working_dir` anchors default paths for CSV, SQLite, log, and start-value outputs; the directory is created if missing
- The literal `[TIME]` in `simulation.recording.csv.file`, `simulation.recording.sqlite.file`, and `simulation.log.file` is replaced with the current timestamp string
- When `simulation.recording.sqlite.file` is absent, the SQLite sink produces a per-run auto-named file `{epoch_seconds}_{session_uuid}.sqlite` in the working directory
- Explicit output paths take precedence over working-directory defaults
