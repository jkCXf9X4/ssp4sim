# REQ-009: Multiple Embedding API Surfaces
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-009 -->

## Description

The engine MUST expose simulation through three embedding surfaces: the CLI application (`sim_app`), a C API, and Python bindings (`pyssp4sim`). All surfaces drive the same init-then-simulate lifecycle against the same JSON configuration.

## Rationale

Different integration scenarios need compatible entry points without a large external runtime: shell scripting and one-shot runs (CLI), C/C++ host applications (C API), and analysis pipelines (Python).

## Acceptance Criteria

- CLI `sim_app <config.json>` performs init and simulate and exits with a status code; `--version` prints the version
- C API exposes create, init, simulate, destroy, and last-error retrieval (`ssp4sim_simulator_create/init/simulate/destroy`, `ssp4sim_last_error`)
- Python `pyssp4sim.Simulator` exposes a config-path constructor, `init()`, and `simulate()`
- All surfaces execute the identical init-to-simulate lifecycle against the same configuration
