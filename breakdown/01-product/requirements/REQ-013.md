# REQ-013: Automatic Analysis and Execution Graph Construction
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-013 -->

## Description

The engine MUST automatically construct the simulation graph from the SSP without manual ordering configuration: parse the SSP into an analysis form, resolve model connections and signal-flow direction, and derive the execution graph dependencies consumed by the executors.

## Rationale

The product goal is a direct path from SSP input to an executable run. Automatic graph construction removes manual interconnection/ordering work and is what makes the executor strategies viable across arbitrary SSP topologies.

## Acceptance Criteria

- The SSP is parsed into an analysis system model (components, connectors, connections) without manual input
- Model-to-model execution edges are derived automatically from resolved connections
- Zero-delay connections are treated as feed-through edges; delay-bearing connections use delayed data-access modes
- Loop-aware execution automatically detects cycles (Tarjan SCC), builds the SCC DAG, and topologically orders execution
- Start values and parameters from SSV/SSM mappings are applied to connectors before initialization
