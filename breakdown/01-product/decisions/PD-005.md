# PD-005: Full JSON File as the Deep-Analysis Logging Tier
<!-- Layer: 01-product -->
<!-- Status: Accepted -->

## Context

Some investigations need the complete structured event stream, not just an operator overview. A JSON file provides a machine-readable archive that can be filtered, searched, or post-processed.

## Decision

Use a full JSON file as the deep-analysis logging tier. It is the canonical local log artifact for offline inspection and automation.

## Rationale

- Structured logs are easier to filter and correlate than free-form text
- JSON is broadly supported by command-line tools and scripts
- Keeping the structured archive separate from the overview tier reduces noise for interactive runs

## Consequences

- The JSON file may be larger than the plain text overview log
- Developers can post-process runs with tooling such as `jq` or Python scripts
- JSON logging should remain enabled only when structured analysis is needed
