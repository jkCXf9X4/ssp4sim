# PD-004: Terminal and File as the Overview Logging Tier
<!-- Layer: 01-product -->
<!-- Status: Accepted -->

## Context

Operators need a low-friction view of simulation progress that works without additional tools. Terminal output gives immediate feedback during a run, and a plain text file preserves the same overview for later inspection.

## Decision

Terminal and plain text file logging form the overview tier for local runs. They are optimized for quick human reading rather than for exhaustive structured analysis.

## Rationale

- Terminal output is visible immediately during startup, execution, and shutdown
- A plain text file preserves the same messages for later review
- The pair covers the most common operational workflow with minimal setup

## Consequences

- Overview logs should stay concise and high-signal
- Critical warnings and failures remain easy to spot without additional tooling
- Deeper structured analysis belongs to the JSON tier
