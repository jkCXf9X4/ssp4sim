# UC-025: Run Concurrent Simulations for Parameter Sweeps
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-025 -->

## Description

A user runs multiple simulations concurrently (e.g. a parameter sweep or Monte Carlo) as separate processes and relies on per-run result artifacts that do not collide.

## Preconditions

- Parameter-sweep or batch harness launches one simulation process per configuration
- Each run uses the SQLite WAL sink without setting `simulation.recording.sqlite.file`

## Flow

1. User leaves `simulation.recording.sqlite.file` absent so each run auto-names its own `{epoch_seconds}_{session_uuid}.sqlite`
2. User runs several simulations in parallel, each writing to the same working directory
3. Each simulation writes its results to its own independent SQLite file
4. User collects the per-run files for analysis/comparison

## Postconditions

- Concurrent runs complete without write-lock contention or file-level append races
- Each run has an independent, queryable result database
