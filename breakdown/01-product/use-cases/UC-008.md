# UC-008: Analyze Full JSON Logs After a Run
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-008 -->

## Description

A developer inspects the full structured JSON log file after a simulation to search, filter, and correlate detailed runtime events.

## Preconditions

- JSON logging is enabled in configuration
- The run completed or the JSON file is otherwise available to the analyst

## Flow

1. Developer runs the simulation with JSON file logging enabled
2. Engine writes structured JSON log records to the configured file
3. Developer opens the file with `jq`, a script, or another structured log tool
4. Developer filters by timestamp, level, subsystem, or message content

## Postconditions

- Full machine-readable logs are available for analysis
- The log archive can be searched and correlated without parsing free-form text
