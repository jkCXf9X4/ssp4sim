# UC-015: Inject a Ramp/Linear (kx+m) Variable Signal During Simulation
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-015 -->

## Description

A user injects a ramp signal of the form kx + m on a variable during simulation. The slope (k) and intercept (m) are configurable, allowing the variable to follow a linear trajectory over simulation time rather than its computed or connected value.

The override may be applied immediately at the current simulation time or scheduled for a specified future simulation time.

### Design Note — Propagation Characteristics

Whether the injected change applies to the output side (feed-through, Gauss-Seidel connections) or the input side (decoupled, Gauss-Jacobi connections) of a variable depends on the propagation characteristics of the connection. This behavior must be configured or determined by the interface design when implemented.

## Preconditions

- Simulation has been initialized and is running
- The simulation engine supports external variable access and signal generation during execution
- The target variable is known by its simulation-internal identifier
- Slope (k) and intercept (m) values are provided by the user

## Flow

1. User specifies the variable identifier, slope (k), and intercept (m)
2. User selects immediate application or scheduled application at a future simulation time
3. Simulation engine computes the ramp value kx + m at each timestep relative to the application time
4. Simulation engine applies the ramp signal to the target variable at the requested time
5. Ramp injection persists until explicitly cleared or superseded

## Postconditions

- The target variable follows the linear trajectory kx + m for each subsequent timestep
- Downstream computation uses the ramp signal (or the original signal, depending on propagation characteristics — see Design Note)
- Simulation continues without interruption

## Current Support

This use case is not implemented yet. The interface to the application/simulation engine is not yet defined.
