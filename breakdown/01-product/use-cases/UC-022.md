# UC-022: Produce Distinct Timestamped Artifacts per Run
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-022 -->

## Description

A user runs repeated simulations and wants each run's result and log artifacts to land in predictable, non-clobbering locations (per-run timestamped or auto-named files).

## Preconditions

- Simulation is configured with at least one result sink and/or log sink
- Path templates use the `[TIME]` substitution, or the SQLite auto-naming is left in default mode

## Flow

1. User sets `simulation.working_dir` to anchor default outputs
2. User optionally uses `[TIME]` in `simulation.recording.csv.file` / `simulation.log.file` (and `simulation.recording.sqlite.file` if a shared path is wanted)
3. User leaves `simulation.recording.sqlite.file` absent to trigger per-run auto-naming (`{epoch_seconds}_{session_uuid}.sqlite`)
4. Engine replaces `[TIME]` with the current timestamp and creates the working directory
5. Engine writes each run's artifacts to the resolved distinct paths

## Postconditions

- Each run produces artifacts in its own timestamped/named files without clobbering previous runs
- Result and log files are discoverable under the configured working directory
