# UC-023: Run a Connected System Without Manual Ordering Configuration
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-023 -->

## Description

A developer runs a multi-model SSP with model interconnections and internal loops without specifying execution order, feed-through, or connection wiring manually. The engine assembles the graph and derives ordering automatically.

## Preconditions

- SSP archive conforms to SSP 1.0 and declares model component connections
- Simulation is configured with start/stop/timestep and an executor method

## Flow

1. User points the configuration at the interconnected SSP
2. Engine parses the SSP into an analysis model (components, connectors, connections) with signal-flow direction
3. Engine resolves connections and derives model-to-model execution edges automatically
4. Engine treats zero-delay connections as feed-through and delay-bearing connections with a delayed data mode
5. For cyclic topology, the loop-aware executor detects loops, topological order, and per-loop iteration count
6. Engine executes and records results

## Postconditions

- Simulation runs across all connected models without manual ordering or wiring input
- Feed-through/delayed connections and any loops are handled by the derived execution graph
- Results are recorded to the configured sinks
