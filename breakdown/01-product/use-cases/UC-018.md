# UC-018: Run a Simulation Paced to Wall Clock
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-018 -->

## Description

An operator runs a simulation paced to wall-clock time so simulation time advances in real time, e.g. for a demonstration or an operator-facing run.

## Preconditions

- SSP archive exists and conforms to SSP 1.0
- `simulation.realtime` is enabled in configuration

## Flow

1. Operator sets `simulation.realtime=true` in the configuration
2. Operator starts the simulation
3. Engine paces each timestep against a wall-clock reference so simulation time tracks real time
4. Operator observes the run progressing at real-time pace

## Postconditions

- Simulation time advances at the wall-clock rate
- Simulation results are identical to an unpaced run (pacing affects timing only)

## Traceability

- Capability: CAP-003 (Multiple Execution Strategies)
- Requirements: REQ-011 (Realtime Wall-Clock Pacing)
