# UC-024: Capture FMU-internal Log Output During a Run
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-024 -->

## Description

A developer enables FMU-level logging so messages emitted by the FMU implementation (during instantiate, setup, step, terminate) are forwarded into the configured log sinks.

## Preconditions

- `simulation.log.fmu` is enabled
- At least one log sink is enabled that is not `disable`
- A loggable FMU (emits FMU-internal log messages) is part of the SSP

## Flow

1. User sets `simulation.log.fmu=true` and configures an overview or deep-analysis sink
2. Engine runs the simulation, forwarding FMU callback messages to the logging sinks
3. Developer inspects the terminal/file/JSON logs for the FMU-internal messages

## Postconditions

- FMU-internal messages appear in the configured log sinks during the run
- FMU logging can be toggled independently of level configuration
