# UC-020: Record Inputs and Start Values for Analysis
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-020 -->

## Description

A user records input signals alongside outputs and captures the applied initial start values to support closed-loop analysis and reproducibility.

## Preconditions

- SSP archive exists and conforms to SSP 1.0
- CSV or local database recording is enabled in configuration

## Flow

1. User sets `simulation.recording.record_inputs=true`
2. User optionally sets a start-values log path via `simulation.log.start_values`
3. User optionally enables `simulation.recording.wait_for` for backpressure when the recorder queue is full
4. Engine runs the simulation; inputs are recorded to the configured sinks alongside outputs
5. Initial start values applied to the FMUs are written to the start-values log
6. User analyzes inputs, outputs, and initial values with the external tooling

## Postconditions

- Input variables appear in the recorded result artifacts
- The start-values log captures the initial values applied at initialization
- Recording queue backpressure is applied when configured

## Traceability

- Requirements: REQ-012 (Configurable Recording Behavior)
