# UC-017: Embed the Engine via the C API
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-017 -->

## Description

A C or C++ host application embeds the simulation engine through the C API and drives it from its own lifecycle.

## Preconditions

- The ssp4sim shared library with the C API is linked into the host application
- A valid JSON configuration file and its referenced SSP archive exist

## Flow

1. Host calls `ssp4sim_simulator_create(config_path, &handle)`
2. Host calls `ssp4sim_simulator_init(handle)`
3. Host calls `ssp4sim_simulator_simulate(handle)`
4. On any failure, host calls `ssp4sim_last_error()` to retrieve the error string
5. Host calls `ssp4sim_simulator_destroy(handle)` to release resources

## Postconditions

- Simulation runs to completion inside the host process
- Host receives status codes for each lifecycle step and can react to failures
- All engine resources are released on destroy

## Traceability

- Capability: CAP-006 (Multiple API Surface)
- Requirements: REQ-009 (Multiple Embedding API Surfaces)
- Sources: `lib/public_include/simulator_c_api.h`
