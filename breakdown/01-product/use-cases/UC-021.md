# UC-021: Simulate a Parameterized SSP Scenario
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-021 -->

## Description

A user runs a simulation whose parameterization is defined by the SSP itself (SSV/SSM or inline parameter bindings) and verifies those values reach the FMUs.

## Preconditions

- SSP archive exists and contains parameter bindings (SSV/SSM or inline)
- Simulation is configured with start/stop/timestep and at least one result sink

## Flow

1. User points the configuration at the SSP containing the scenario parameterization
2. Engine parses the parameter bindings and resolves them against the connector tree
3. Engine applies the matched values to FMU parameters and inputs at initialization
4. User inspects the start-values artifact and result outputs to confirm the scenario values took effect

## Postconditions

- FMU parameters and inputs reflect the SSP's parameterization at initialization
- Applied start values are recorded in the start-values artifact and result sinks
