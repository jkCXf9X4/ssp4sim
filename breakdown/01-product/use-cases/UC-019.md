# UC-019: Experiment with Executor Variants and Tuning
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-019 -->

## Description

A developer runs the same SSP with different executor variants and tuning parameters to study coupling behavior, loop handling, and performance.

## Preconditions

- Same as UC-001
- User has configuration files that differ in executor variant and tuning keys

## Flow

1. User configures `simulation.executor.method` (e.g. `jacobi`, `seidel`, `loop_aware`, `custom_delay`, `custom_delay_partial`)
2. User selects variants such as `simulation.executor.jacobi.parallel` with `simulation.executor.jacobi.method` (1=TBB, 2=spin, 3=futures), `simulation.executor.seidel.parallel`, or a sub-step via `simulation.executor.sub_step`
3. User tunes `simulation.executor.thread_pool_workers` and `simulation.executor.forward_derivatives`
4. User runs each configuration, recording results to separate output artifacts
5. User compares results and performance across runs

## Postconditions

- Each variant run completes and produces its own recorded artifact
- Results and timing are comparable across variants
