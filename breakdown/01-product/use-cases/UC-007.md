# UC-007: Review Simple Overview Logs During a Run
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-007 -->

## Description

An operator watches the terminal and a plain text log file during a simulation to confirm basic progress and diagnose a simple failure.

## Preconditions

- Simulation config enables terminal and file logging
- Log levels are set to an overview-oriented profile

## Flow

1. Operator starts the simulation with terminal and file sinks enabled
2. Engine emits startup, scenario selection, and completion messages
3. Warnings and errors appear immediately in the terminal
4. The same messages are persisted to a file for later review

## Postconditions

- Operator gets a fast human-readable view of run status
- Persistent logs remain available after the run completes
