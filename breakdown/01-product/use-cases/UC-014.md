# UC-014: Inject a Phase-Shifted Variable Signal During Simulation
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-014 -->

## Description

A user injects a phase-shifted version of a variable's signal during simulation. The phase-shifted signal tracks the original variable's value but applies a configurable phase angle or delay offset.

The override may be applied immediately at the current simulation time or scheduled for a specified future simulation time.

### Design Note — Propagation Characteristics

Whether the injected change applies to the output side (feed-through, Gauss-Seidel connections) or the input side (decoupled, Gauss-Jacobi connections) of a variable depends on the propagation characteristics of the connection. This behavior must be configured or determined by the interface design when implemented.

## Preconditions

- Simulation has been initialized and is running
- The simulation engine supports external variable access and signal transformation during execution
- The source variable is known by its simulation-internal identifier
- A phase-shift angle or delay value is computable by the simulation engine

## Flow

1. User specifies the source variable identifier and the phase-shift angle or delay
2. User selects immediate application or scheduled application at a future simulation time
3. Simulation engine computes the phase-shifted signal from the source variable's history
4. Simulation engine applies the transformed signal to the target at the requested time
5. Phase-shifted injection persists until explicitly cleared or superseded

## Postconditions

- The target variable follows a phase-shifted version of the source signal
- Downstream computation uses the phase-shifted signal (or the original signal, depending on propagation characteristics — see Design Note)
- Simulation continues without interruption

## Current Support

This use case is not implemented yet. The interface to the application/simulation engine is not yet defined.
