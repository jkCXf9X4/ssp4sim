# VD-001: C++ for Unit Tests, Python for Workflow Tests
<!-- Layer: 04-verification -->
<!-- Status: Accepted -->

## Context

The test suite uses both C++ (Catch2) and Python (pytest) for different testing levels. C++ tests cover low-level library behavior. Python tests cover end-to-end workflows.

## Decision

Use C++ Catch2 for unit and integration tests. Use Python pytest for workflow-level tests and result validation.

## Rationale

- C++ tests run without Python interpreter overhead for tight-loop primitives
- Python pytest provides superior fixture management, parameterization, and xfail tracking
- Reference sweeps are easier to maintain in Python with file discovery tools

## Consequences

- Build system must produce both test artifacts (C++ binary + Python extension)
- Reference fixture discovery is Python-side only
- Some tests have dual coverage (C++ smoke + Python workflow) by design
