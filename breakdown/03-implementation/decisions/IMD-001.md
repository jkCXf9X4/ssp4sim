# IMD-001: Use C++23 Standard
<!-- Layer: 03-implementation -->
<!-- Status: Accepted -->

## Context

SSP4SIM is written in C++23. This enables a modern C++ feature set: designated initializers, std::expected for error handling, std::optional for optional values, std::span for bounded views, and std::string_view for string references.

## Decision

Use C++23 as the implementation language standard. Require GCC 13+ or Clang 16+.

## Rationale

- C++23 features reduce boilerplate and improve safety (std::expected vs. exceptions for expected errors)
- Designated initializers improve configurability readability
- std::span provides safe bounded views over contiguous memory
- The target audience (C++ developers) is familiar with modern C++

## Consequences

- Requires relatively new toolchains (GCC 13+, Clang 16+)
- Some library support (std::expected) may still be stabilizing
- Excludes older compiler versions that may be default on some Linux distributions

## Traceability

- Backward: Build environment (GCC 13+, Clang 16+ requirement).
- Sources: `CMakeLists.txt` (C++23 standard declaration), `docs/development.md`.
