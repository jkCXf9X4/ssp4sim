# TD-001: Use Catch2 for C++ Tests
<!-- Layer: 03-implementation -->
<!-- Status: Accepted -->

## Context

C++ unit and integration tests use the Catch2 testing framework.

## Decision

Use Catch2 for C++ tests. Test files follow the `test_*.cpp` naming convention.

## Rationale

- Catch2 is header-only (v2) or minimal (v3), easy to integrate
- Supports BDD-style sections, test case tagging, and custom reporters
- Well-established in the C++ ecosystem

## Consequences

- Catch2 is a build dependency (handled via vcpkg)
- CTest is the canonical test runner — see `docs/build_from_source.md` and `tests/README.md` for run commands.
- Test naming follows Catch2 conventions (TEST_CASE, SECTION)
