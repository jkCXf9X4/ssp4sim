# TD-002: Use pytest for Python Workflow Tests
<!-- Layer: 03-implementation -->
<!-- Status: Accepted -->

## Context

Python-level workflow tests use pytest for test execution and fixture management.

## Decision

Use pytest for Python tests. Tests discover reference SSP fixtures through pytest parameterization.

## Rationale

- Pytest provides superior parameterization for reference sweeps
- Fixture discovery and comparison tools are Python-side
- xfail markers track known issues at the test level

## Consequences

- Python 3.9+ required for the test environment
- Tests import pyssp4sim from build directory (not installed wheel)
- Two Python test files: high-level reference sweep + CLI smoke test

## Traceability

- Backward: Verification decision VD-001 (Python for workflow tests).
- Sources: `tests/python/`, `tests/python/conftest.py`.
