# OD-003: Logging Levels Configurable at Runtime
<!-- Layer: 05-operation -->
<!-- Status: Accepted -->

## Context

Operators need different logging verbosity for development vs. production use. Log levels are set per-sink in the configuration file.

## Decision

Logging levels are configurable per-sink at runtime via the JSON configuration file. Hot-path logging can additionally be compiled out for maximum performance.

## Rationale

- Runtime configurability avoids rebuilds for log level changes
- Per-sink levels enable different verbosity per output (terminal=debug, file=info)
- Compile-time disable (SSP4SIM_LOG_HOT_PATH) eliminates hot-path overhead

## Consequences

- Operators can adjust verbosity without rebuilding
- Hot-path tracing requires a separate build with SSP4SIM_LOG_HOT_PATH=ON
- Log level configuration is in the same JSON file as simulation settings
