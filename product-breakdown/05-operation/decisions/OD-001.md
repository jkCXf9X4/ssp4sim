# OD-001: CSV as Default Recording Format
<!-- Layer: 05-operation -->
<!-- Status: Accepted -->

## Context

Simulation results can be recorded to CSV (default) or DuckDB. Operators may need to choose between portability and queryability.

## Decision

CSV is the default recording format. DuckDB is optional.

## Rationale

- CSV is universally portable, requires no additional tooling
- Integrates with existing analysis pipelines
- DuckDB adds a build dependency

## Consequences

- CSV output always available; DuckDB requires build-time linkage
- Operators needing queryable output should enable DuckDB
- Both formats can operate concurrently
