# OD-001: Local Database as Default Recording Format
<!-- Layer: 05-operation -->
<!-- Status: Accepted -->

## Context

Simulation results can be recorded to a local database (default) or CSV export. Operators may need to choose between queryability and portability.

## Decision

The local database is the default recording format. CSV is optional as a portable export path.

## Rationale

- The local database is the primary query layer for time-window and run-comparison workflows
- CSV is universally portable, requires no additional tooling

## Consequences

- Local database output is available for primary query workflows
- Operators needing a portable export should enable CSV
- Both formats can operate concurrently
