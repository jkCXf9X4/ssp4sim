# VD-003: DuckDB Recorder Tests Cover CSV Recorder Gap
<!-- Layer: 04-verification -->
<!-- Status: Accepted -->

## Context

DuckDB recorder has dedicated C++ unit tests (`tests/lib/core/test_duckdb_recorder.cpp`). CSV recorder does not have a dedicated unit test — it is tested only through the C++ high-level smoke test and Python workflow tests.

## Decision

Accept the CSV recorder unit test gap. CSV recorder coverage through the smoke test and workflow tests is sufficient for the experimental phase.

## Rationale

- CSV recording is exercised in every workflow test that produces output
- Adding a CSV-specific unit test would duplicate what is already covered
- DuckDB has a dedicated test because its output format (database tables) requires structured data layout validation
- The CSV recorder is simpler (row-oriented, no schema) and less likely to have format-specific bugs

## Consequences

- CSV format compliance is not validated in isolation
- If CSV-specific bugs appear, a dedicated unit test should be added
- The coverage gap is documented in coverage-targets.md
