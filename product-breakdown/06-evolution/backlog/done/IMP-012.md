# IMP-012: Consolidate "Ctest Is Unreliable" Note To One Canonical Location

## Status

Proposed

## Layer

04-verification

## Theme

The same note — "ctest --test-dir build/tests is currently unreliable" — appears in three files. Consolidate to one canonical location and cross-link from the others.

## Evidence

Three occurrences of the same factual statement:

1. `docs/build_from_source.md`, line 109: "\"ctest --test-dir build/tests\" is currently unreliable. Run the `./build/tests/lib/ssp4sim_tests` binary directly"
2. `tests/README.md`, line 40: "\"ctest --test-dir build/tests\" is currently unreliable. Run the test binary directly."
3. `product-breakdown/04-verification/test-strategy.md`, line 34: "\"ctest --test-dir build/tests\" is unreliable -- run the test binary directly."

All three say essentially the same thing with minor wording variations.

## Current Pain Or Risk

- **Drift risk**: If ctest becomes reliable (e.g., after a CMake or Catch2 upgrade), the note must be removed from all three files or the repository will have contradictory guidance.
- **Trivial maintenance**: Every time someone reads one of these files and finds an old note, they wonder if the others have been updated.

## Proposed Improvement

1. Keep the canonical note in `tests/README.md` (the test-runner's own README), where it has the most context — right next to the test commands it qualifies.
2. In `docs/build_from_source.md`, replace the ctest note with a cross-link: "See tests/README.md for testing caveats."
3. In `product-breakdown/04-verification/test-strategy.md`, replace the ctest note with a cross-link: "See tests/README.md for testing caveats."

## Expected Benefit

- Single point of truth for test-running caveats.
- When ctest is fixed, only `tests/README.md` needs updating.

## Risk And Blast Radius

- **Blast radius**: 3 files, minor text changes (remove 1 line each from build_from_source.md and test-strategy.md).
- **Risk**: Low. Text changes only.

## Suggested Priority

Medium — low effort, moderate improvement in maintenance hygiene.

## Task Contract Seed

The smallest scoped task:

1. Open `docs/build_from_source.md`. Replace the ctest sentence with: "See `tests/README.md` for test-running caveats."
2. Open `product-breakdown/04-verification/test-strategy.md`. Replace the ctest sentence with: "See `tests/README.md` for test-running caveats."
3. Ensure `tests/README.md` still has the canonical note. No change needed there.

## Out Of Scope

- Do not change the structure or other content of any file.
- Do not fix ctest itself (that is a separate infrastructure task).
