# REQ-003: Configurable Execution Strategy
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-003 -->

## Description

The engine MUST support selecting the execution strategy (Gauss-Jacobi, Gauss-Seidel) at runtime through configuration.

## Rationale

Different simulation scenarios benefit from different execution strategies. Runtime selection enables experimentation without rebuilds.

## Acceptance Criteria

- `executor.method` config key selects strategy
- Gauss-Jacobi with parallel and serial variants
- Gauss-Seidel with parallel and serial variants
- Custom delay-oriented executors are available
