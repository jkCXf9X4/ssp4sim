# REQ-005: DuckDB Output with Per-Storage Tables
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-005 -->

## Description

The engine MUST support recording simulation results to DuckDB with per-storage tables.

## Rationale

DuckDB provides a structured queryable output for large simulation datasets, enabling analysis without CSV parsing.

## Acceptance Criteria

- DuckDB output is produced when duckdb.enable is true
- Each signal storage area creates a separate table
- DuckDB output is written to the configured working directory
- DuckDB recording can run alongside CSV recording
