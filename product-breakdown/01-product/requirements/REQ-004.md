# REQ-004: CSV Output with Configurable Sample Interval
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-004 -->

## Description

The engine MUST support CSV export with a configurable sample interval.

## Rationale

CSV is the portable export format. The sample interval controls output granularity without affecting simulation internals.

## Acceptance Criteria

- CSV output is produced when csv.enable is true
- Recording interval is configurable via csv.interval
- CSV rows are coalesced by timestamp across storages
- Output is written to the configured working directory
