# REQ-007: Distributed Observability via OpenTelemetry
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-REQ-007 -->

## Description

The engine MUST provide a distributed observability export path using OpenTelemetry for simulations that span multiple processes or services.

## Rationale

Local logs are sufficient for a single run on one host. Distributed simulations need trace correlation, span hierarchies, and shared identifiers across process boundaries.

## Acceptance Criteria

- Simulation runs can emit OpenTelemetry trace data for distributed execution paths
- Trace context can be propagated across simulation boundaries
- Result metadata such as run id, scenario, model, and storage identity can be attached to traces
- Distributed observability can be enabled or disabled independently of local log sinks
