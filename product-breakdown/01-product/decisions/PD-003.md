# PD-003: DuckDB as Optional Recording Backend
<!-- Layer: 01-product -->
<!-- Status: Accepted -->

## Context

DuckDB recording is an optional alternative to the default CSV recording. It requires DuckDB library linkage and adds a dependency.

## Decision

DuckDB is an optional recording backend. It is NOT a replacement for CSV — both can operate concurrently on the same event stream.

## Rationale

- DuckDB offers better query capabilities for large simulation datasets
- DuckDB offers better support for dynamic timesteps where all models do not synchronize at each macro step
- CSV remains the default for portability and simplicity
- Concurrent operation allows users to adopt DuckDB gradually
- The recording pipeline is designed for multiple sinks

## Consequences

- DuckDB support requires an additional build dependency
- Users without DuckDB support still get CSV output
- Both formats produce the same data (same event stream, different serialization)
