# PD-006: Cutelog as the Live Structured Log Navigation Tier
<!-- Layer: 01-product -->
<!-- Status: Accepted -->

## Context

Operators sometimes need the full structured log stream while a simulation is still running. A live viewer is more useful than waiting for the run to finish when the goal is to navigate a large or noisy log stream.

## Decision

Use cutelog as the live structured log navigation tier. It is the interactive view over the same structured JSON event stream used by the deep-analysis tier.

## Rationale

- Cutelog makes it easier to jump through a live event stream than raw terminal output
- The sink preserves structure while allowing real-time inspection
- It complements, rather than replaces, the terminal and JSON tiers

## Consequences

- The sink depends on a live listener being available
- The sink is best treated as a navigation aid, not a durable archive
- If the listener is unavailable, the rest of the logging profile should still work
