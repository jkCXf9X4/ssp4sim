# PD-001: CSV as Primary Output
<!-- Layer: 01-product -->
<!-- Status: Accepted -->

## Context

Simulation results can be recorded to CSV (default) or DuckDB. CSV recording writes one file per simulation run with configurable interval. DuckDB writes per-storage tables.

## Decision

CSV is the primary and default recording format. DuckDB is an optional alternative backend.

## Rationale

- CSV is universally portable and requires no additional tooling to read
- CSV output integrates with existing analysis pipelines (pandas, R, spreadsheets)
- DuckDB offers better performance for large datasets but adds a dependency

## Consequences

- CSV output is always available; DuckDB requires library linkage
- Recording pipeline supports both sinks on the same event stream
- DuckDB may become more prominent if performance requirements grow
- CSV is NOT treated as the preferred data interchange format; the input data policy in `docs/usage.md` explicitly avoids treating CSV as a long-term interchange format
