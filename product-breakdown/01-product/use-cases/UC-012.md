# UC-012: Adjust Simulation Speed
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-012 -->

## Description

A user adjusts the real-time speed of a running simulation to control how fast or slow the simulation progresses relative to wall-clock time.

## Preconditions

- Simulation has been initialized and is running
- The simulation engine supports dynamic speed adjustment

## Flow

1. User sets a speed factor (e.g., 0.0 for maximum speed, 1.0 for real-time, 2.0 for double speed)
2. Simulation adjusts its real-time pacing to match the requested speed factor
3. Simulation continues running at the new speed

## Postconditions

- Simulation runs at the requested speed factor
- Speed adjustment does not affect simulation results (only wall-clock timing)

## Current Support

This use case is not implemented yet. The current `simulation.realtime` configuration flag provides a binary real-time toggle, but dynamic speed adjustment during execution is not supported.
