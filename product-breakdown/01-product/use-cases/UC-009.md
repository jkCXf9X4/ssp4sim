# UC-009: Navigate Live Structured Logs in Cutelog
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-009 -->

## Description

An operator watches a live structured log stream in cutelog to jump through a running simulation without scanning raw text.

## Preconditions

- Cutelog sink is enabled in configuration
- A cutelog listener is running on the configured host and port

## Flow

1. Operator starts cutelog before launching the simulation
2. Engine emits JSON-formatted log events to the cutelog sink
3. Operator uses cutelog to jump between events, levels, and components
4. The live stream remains useful for the duration of the run

## Postconditions

- Operator can navigate the current run interactively
- Structured logs remain readable while the simulation is active
