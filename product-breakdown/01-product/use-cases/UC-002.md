# UC-002: Compare Execution Strategy Results
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-002 -->

## Description

A developer runs the same SSP with different execution strategies to compare results and performance.

## Preconditions

- Same as UC-001
- User has two configuration files with different executor strategies

## Flow

1. User runs simulation with Gauss-Jacobi configuration
2. Results are recorded to CSV or DuckDB
3. User runs simulation with Gauss-Seidel configuration
4. Results are recorded to separate output files
5. User compares output files for differences

## Postconditions

- Both simulations complete
- Results are comparable across strategies

- Capability: CAP-003 (Multiple Execution Strategies)
