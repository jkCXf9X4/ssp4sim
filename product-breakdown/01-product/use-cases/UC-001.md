# UC-001: Run a Co-Simulation from an SSP Archive
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-001 -->

## Description

A user runs a complete co-simulation workflow from an SSP archive using the CLI.

## Preconditions

- SSP archive exists and conforms to SSP 1.0
- FMUs in the archive are valid FMI 2.0 co-simulation models
- A JSON configuration file exists

## Flow

1. User invokes `sim_app <config.json>` with a configuration pointing to the SSP
2. Engine loads and parses the SSP archive
3. FMUs are loaded and instantiated
4. Analysis graph is built from SSP models and connections
5. Execution graph is built with the configured executor strategy
6. Simulation advances from start_time to stop_time
7. Results are recorded to the configured output

## Postconditions

- Simulation completes without errors
- Results are written to CSV or DuckDB
- All FMU instances are cleaned up
