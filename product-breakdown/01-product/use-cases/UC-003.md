# UC-003: Embed the Engine in a Python Workflow
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-003 -->

## Description

A user imports pyssp4sim in a Python script to integrate simulation results into a larger analysis pipeline.

## Preconditions

- pyssp4sim wheel is installed
- SSP archive exists
- User has Python 3.9+ environment

## Flow

1. User imports pyssp4sim in Python
2. Creates a Simulator instance with a config path
3. Calls init() and simulate()
4. Processes results (CSV files or DuckDB tables) with Python tools

## Postconditions

- Simulation runs to completion
- Results are accessible for further analysis in Python
