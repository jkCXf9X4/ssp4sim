# UC-011: Pause, Resume, and Stop a Simulation
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-011 -->

## Description

A user pauses, resumes, or stops a running simulation to control execution interactively.

## Preconditions

- Simulation has been initialized and is running (via `simulate()` or `play()`)
- The simulation engine supports lifecycle state transitions

## Flow

1. User pauses the running simulation
2. Simulation suspends execution at the next timestep boundary; current simulation time and state are preserved
3. User resumes the simulation
4. Simulation continues execution from the paused simulation time
5. User stops the simulation
6. Simulation terminates immediately; results up to the last completed timestep are recorded and preserved

## Postconditions

- After pause: simulation is suspended; can be resumed or stopped
- After resume: simulation continues from the paused state
- After stop: simulation is terminated; partial results are preserved; all FMU resources are cleaned up

## Current Support

This use case is not implemented yet. It is the planned interactive lifecycle control tier beyond the current one-shot `simulate()` API.
