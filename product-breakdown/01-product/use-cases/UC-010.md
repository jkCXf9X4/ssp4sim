# UC-010: Correlate Distributed Simulation Behavior with OpenTelemetry
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-010 -->

## Description

A developer or operator inspects a distributed simulation run through OpenTelemetry traces to understand cross-process timing and causality.

## Preconditions

- Distributed observability export is implemented
- Trace collection and viewing infrastructure is available

## Flow

1. Simulation components emit OpenTelemetry trace data during a distributed run
2. Trace context is propagated across process boundaries
3. The trace backend stores spans and attributes from the run
4. The user reviews the distributed trace to understand end-to-end behavior

## Postconditions

- Cross-process timing and parent-child relationships are visible in one view
- Distributed simulations can be analyzed without stitching together local logs by hand

## Current Support

This use case is not implemented yet. It is the planned distributed observability tier beyond the current local logging sinks.
