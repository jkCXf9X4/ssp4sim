# UC-004: Record Results to CSV for External Analysis
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-004 -->

## Description

A user runs a simulation with CSV recording enabled and processes the results with external tools.

## Preconditions

- SSP archive exists and conforms to SSP 1.0
- CSV recording is enabled in configuration (default)

## Flow

1. User configures simulation with CSV recording enabled
2. User sets recording interval in configuration
3. Engine runs simulation with CSV recorder sink attached
4. Recorder writes CSV output for each storage
5. Results are available at the configured output path

## Postconditions

- CSV file(s) written with simulation results
- Headers match storage variable names
- Rows are coalesced by timestamp across storages
