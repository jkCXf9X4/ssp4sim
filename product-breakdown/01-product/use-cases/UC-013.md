# UC-013: Inject a Direct Variable Override During Simulation
<!-- Layer: 01-product -->
<!-- Stable ID: PRO-UC-013 -->

## Description

A user injects a fixed value override on a specified variable (output or input) during simulation, overriding its computed or connected value with a user-specified constant.

The override may be applied immediately at the current simulation time or scheduled for a specified future simulation time.

### Design Note — Propagation Characteristics

Whether the injected change applies to the output side (feed-through, Gauss-Seidel connections) or the input side (decoupled, Gauss-Jacobi connections) of a variable depends on the propagation characteristics of the connection. This behavior must be configured or determined by the interface design when implemented.

## Preconditions

- Simulation has been initialized and is running
- The simulation engine supports external variable access and write capability during execution
- The target variable is known by its simulation-internal identifier

## Flow

1. User specifies the variable identifier and a fixed override value
2. User selects immediate application (at current simulation time) or scheduled application (at a specific future simulation time)
3. Simulation engine applies the override at the requested time
4. Override persists until explicitly cleared or superseded by a subsequent override

## Postconditions

- The target variable holds the override value at the applied simulation time
- Downstream computation uses the overridden value (or the original value, depending on propagation characteristics — see Design Note)
- Simulation continues from the override point without interruption

## Current Support

This use case is not implemented yet. The interface to the application/simulation engine is not yet defined.
