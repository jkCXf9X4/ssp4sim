# Refactoring and cleanup of graph builder files

**Question:** Should `analysis_graph_builder.cpp` and `graph_builder.cpp` be refactored for readability and maintainability?

**Evidence:** Findings include a 47-line commented-out dead block, parameter/member shadowing, an unused return value, inconsistent includes/error prefixes/`or` vs `||`, two monolithic `build()` methods (~108 and ~128 lines), repeated causality checks, unsafe downcasts, an early/late `ofstream`, and a redundant `std::move`.

**Change:** Remove dead code, unify parameter and error conventions, extract per-phase private helpers from both `build()` methods, consolidate causality checks, and replace unsafe downcasts.

**Risk:** Low-medium per finding — builder files and headers plus tests; public interfaces preserved; each finding is independently actionable.

**Acceptance:** Both builders are clean, readable, and consistent with no dead code; existing graph construction behavior and tests are unchanged.
