# Canonicalize project purpose statement to the intent layer

**Question:** Should the project purpose sentence live only in the intent layer, with readme and overview linking instead of repeating it?

**Evidence:** The same purpose sentence appears verbatim in `readme.md`, the intent purpose leaf, and `docs/overview.md`, with a parenthetical wording variation ("System Structure and Parameterization" vs "Structure and Parameterization"); the intent layer owns the why.

**Change:** Keep the canonical statement in the intent purpose leaf (resolving the parenthetical to the SSP-standard form), and replace the repeated purpose in readme and overview with a concise tagline plus a link.

**Risk:** Low — three files, minor text changes; purpose content unchanged.

**Acceptance:** One canonical "why" statement in the intent layer; readme and overview link rather than reproduce.
