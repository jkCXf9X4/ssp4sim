# Consolidate fmi4c mode-bit documentation to one location

**Question:** Should the fmi4c loader mode-bit explanation be consolidated into the dependency-policy leaf?

**Evidence:** Three files state that the fmi4c loader marks Linux shared libraries executable before dlopen and that this can dirty Git-tracked fixtures; the dependency-policy leaf is the natural policy owner for vendored dependency behavior.

**Change:** Keep the canonical explanation in the dependency-policy leaf (expanded to include the copy-to-temp action guidance), and replace the statements in the test-strategy leaf and `tests/README.md` with cross-links.

**Risk:** Low — text changes only; the policy file keeps its content.

**Acceptance:** One policy owner for the mode-bit explanation; other files point at it; tests still prefer copying mutable fixtures to temp directories.
