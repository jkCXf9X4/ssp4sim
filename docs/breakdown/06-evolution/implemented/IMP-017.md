# Deduplicate test pyramid description between tests/README and the strategy leaf

**Question:** Should the three-layer test pyramid description be differentiated so the strategy leaf owns rationale and `tests/README.md` owns layout?

**Evidence:** Both `tests/README.md` and the verification test-strategy leaf describe the three test layers with substantially similar purpose text; only the strategy leaf adds the strategic rationale and traceability.

**Change:** Condense the strategy leaf's layer descriptions to strategic statements and remove concrete file paths; add cross-links in both directions.

**Risk:** Low — text changes only across two files.

**Acceptance:** Strategy (why each layer exists, what it gates) and layout (file locations, run commands) are cleanly separated.
