# Deduplicate generated-data policy between docs and PBS

**Evidence:** Both files carry the generated-data handling policy (build outputs, unpacked archives, result CSVs, logs, FMU/SSP binaries), Python environment guidelines, and related handling instructions with different wording; the PBS leaf is the stable design home.

**Risk:** Low — two files, ~10 lines removed from docs; removed text is a subset of the PBS leaf's content.

**Acceptance:** `docs/development.md` carries no policy duplication and links to the authoritative leaf; the dependency-policy leaf is unchanged.
