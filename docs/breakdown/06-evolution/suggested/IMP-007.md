# Rename jacobi_serial to Gauss-Seidel plus hybrid executor sketch

**Question:** Should the `jacobi_serial` executor variant be renamed `gauss_seidel`, and is a hybrid executor sketch worth drafting on top of the renamed family?

**Evidence:** The name `jacobi_serial` is misleading because the sequential variant is algorithmically Gauss-Seidel iteration. The rename is still open and referenced as complementary by `IMP-025` and `IMP-028`.

**Change:** Rename `jacobi_serial` to `gauss_seidel` in `executor_builder.cpp`, module docs, and `docs/configuration.md`; add a hybrid executor design sketch building on the renamed family and on `IMP-021`/`IMP-025`.

**Risk:** Moderate blast radius for the rename (executor_builder.cpp, configuration docs, module docs); the sketch itself is documentation only. No behavioral change intended.

**Acceptance:** The variant is selectable as `gauss_seidel` with no stale `jacobi_serial` references; a hybrid design sketch exists in the evolution layer.
