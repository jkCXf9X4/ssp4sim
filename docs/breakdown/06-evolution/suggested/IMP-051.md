# Set the read target resolver during the pipeline

**Question:** Should the read target resolver be set during the pipeline instead of where it is assigned today?

**Evidence:** A raw developer note says the read target resolver should be set during the pipeline and that the design should be nailed down before patching anything.

**Change:** Design where the resolver is installed in the pipeline, then move resolver assignment to that point.

**Risk:** Unknown — resolver installation affects the whole read path; design-first is explicitly requested.

**Acceptance:** A design note records the intended resolver installation point; the change is implemented only after the design is agreed.
