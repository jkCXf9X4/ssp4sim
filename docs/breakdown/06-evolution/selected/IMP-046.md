# la2 hybrid warm-started SCC iteration and sub-step input interpolation

**Question:** Can the la2 hybrid's dominant cost — fixed-count SCC sub-step relaxation — be reduced by warm-starting the iteration and interpolating sub-step inputs?

**Evidence:** Timing analysis shows per-call model wall-clock inflation ~1.3–1.7x (up to ~3.5x in the pinned benchmark) from the 4x sub-step sweep, not extra FMU work. Forward derivatives are a convergence/accuracy mechanism, not a cost (disabling them slows runs). The new derivative recording exports per-signal `.d1` columns anchored to their sub-timestep, so changes are verifiable.

**Change:** Warm-start each sub-step from the latest committed values (fixed iteration count first, then convergence-based early termination), and evaluate sub-step input interpolation from the latest value plus the forwarded order-1 derivative; compare against the documented steady-state and transient envelopes and per-call walltime.

**Risk:** Moderate — core la2 stack files only, no flat-family or API changes; warm-starting shifts the numerical path, so parity with baseline la2 and jacobi steady state must be re-verified; determinism risk is low with a fixed iteration count, medium with early termination.

**Acceptance:** Steady state within the documented 0.09%/0.05% envelopes and transient within the documented envelope; per-call walltime improves toward the fine-step baseline; derivatives stay anchored via `record_derivatives`; default behavior unchanged until proven.
