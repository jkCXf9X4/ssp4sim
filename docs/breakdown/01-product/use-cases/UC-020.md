# UC-020: Record Inputs and Start Values for Analysis

- **Actor:** user running a simulation with recording enabled.
- **Goal:** "record input signals alongside outputs and capture the applied initial start values for closed-loop analysis and reproducibility."
- **Outcome:** input variables appear in the recorded result artifacts; the start-values log captures the initial values applied at initialization; recording queue backpressure is applied when configured.
- **Capability:** configurable recording behavior (`CP-001`).
- **Satisfies:** `REQ-012`.
