# UC-004: Record Results to CSV for External Analysis

- **Actor:** user needing portable, scriptable output.
- **Goal:** "record a run to CSV with my chosen sample interval and process the results with external tools."
- **Outcome:** CSV files are written with headers matching storage variable names and rows coalesced by timestamp across storages.
- **Capability:** CSV recording (`CP-001`).
- **Satisfies:** `REQ-004`.
