# UC-017: Embed the Engine via the C API

- **Actor:** C or C++ host application linking the engine's C API.
- **Goal:** "embed the simulation engine in my host process and drive it from my own lifecycle."
- **Outcome:** the simulation runs to completion inside the host process; the host receives status for each lifecycle step and can react to failures; all engine resources are released.
- **Capability:** C API surface (`CP-001`).
- **Satisfies:** `REQ-009`.
