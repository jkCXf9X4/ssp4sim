# UC-018: Run a Simulation Paced to Wall Clock

- **Actor:** operator running a demonstration or operator-facing run.
- **Goal:** "run a simulation so simulation time advances in sync with wall-clock time."
- **Outcome:** simulation time advances at the wall-clock rate; results are identical to an unpaced run because pacing affects timing only.
- **Capability:** real-time pacing (`CP-001`).
- **Strain:** pacing is not a hard real-time guarantee (`CON-001`).
- **Satisfies:** `REQ-011`.
