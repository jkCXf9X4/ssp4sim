# UC-013: Inject a Direct Variable Override During Simulation

- **Actor:** user with a running simulation and knowledge of the target variable.
- **Goal:** "inject a fixed value override on a specified variable, immediately or at a scheduled future simulation time."
- **Outcome:** the target variable holds the override value at the applied simulation time; downstream computation uses the overridden value; the simulation continues without interruption.
- **Capability:** variable injection and scheduling (`CP-001`).
- **Status:** planned; the interface is not yet defined.
- **Strain:** whether the override applies to the output side or the input side of a variable depends on the connection's propagation characteristics.
