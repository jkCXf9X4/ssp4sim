# UC-024: Capture FMU-internal Log Output During a Run

- **Actor:** developer with a loggable FMU and FMU logging enabled.
- **Goal:** "capture messages emitted by the FMU implementation during the run and route them into my configured log sinks."
- **Outcome:** FMU-internal messages appear in the configured log sinks during the run; FMU logging toggles independently of level configuration.
- **Capability:** local logging tiers (`CP-001`).
- **Satisfies:** `REQ-006`.
