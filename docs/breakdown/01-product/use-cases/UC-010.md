# UC-010: Correlate Distributed Simulation Behavior with OpenTelemetry

- **Actor:** developer or operator with trace collection and viewing infrastructure available.
- **Goal:** "inspect a distributed simulation run through traces to understand cross-process timing and causality."
- **Outcome:** cross-process timing and parent-child relationships are visible in one view; distributed simulations are analyzed without stitching together local logs by hand.
- **Capability:** distributed observability (`CP-001`).
- **Status:** planned, not yet implemented (`IMP-031`).
- **Satisfies:** `REQ-007`.
