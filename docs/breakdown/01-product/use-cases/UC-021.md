# UC-021: Simulate a Parameterized SSP Scenario

- **Actor:** user with an SSP containing parameter bindings.
- **Goal:** "run a simulation whose parameterization comes from the SSP and verify those values reach the FMUs."
- **Outcome:** FMU parameters and inputs reflect the SSP's parameterization at initialization; applied start values are recorded in the start-values artifact and result sinks.
- **Capability:** SSP parameter and start-value application (`CP-001`).
- **Satisfies:** `REQ-015`.
