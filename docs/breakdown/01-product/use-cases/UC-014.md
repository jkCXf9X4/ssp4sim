# UC-014: Inject a Phase-Shifted Variable Signal During Simulation

- **Actor:** user with a running simulation and a computable phase angle or delay.
- **Goal:** "inject a phase-shifted version of a variable's signal, immediately or at a scheduled future simulation time."
- **Outcome:** the target variable follows a phase-shifted version of the source signal; the simulation continues without interruption.
- **Capability:** variable injection and scheduling (`CP-001`).
- **Status:** planned; the interface is not yet defined.
- **Strain:** whether the injected signal applies to the output side or the input side depends on the connection's propagation characteristics.
