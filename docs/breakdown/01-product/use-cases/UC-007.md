# UC-007: Review Simple Overview Logs During a Run

- **Actor:** operator with an overview-oriented log profile enabled.
- **Goal:** "watch the terminal and a plain-text log file during a run to confirm progress and diagnose a simple failure."
- **Outcome:** warnings and errors appear immediately in the terminal; a fast human-readable view of run status is available; persistent logs remain after the run completes.
- **Capability:** local logging tiers (`CP-001`).
- **Satisfies:** `REQ-006`.
