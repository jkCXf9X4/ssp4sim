# UC-023: Run a Connected System Without Manual Ordering Configuration

- **Actor:** developer with an interconnected multi-model SSP.
- **Goal:** "run a multi-model SSP with interconnections and internal loops without specifying execution order, feed-through, or wiring manually."
- **Outcome:** the simulation runs across all connected models; feed-through and delayed connections and any loops are handled by the derived execution graph; results are recorded to the configured sinks.
- **Capability:** automatic analysis and execution graph construction (`CP-001`).
- **Satisfies:** `REQ-013`.
