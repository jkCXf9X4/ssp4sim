# UC-022: Produce Distinct Timestamped Artifacts per Run

- **Actor:** user running repeated or concurrent simulations.
- **Goal:** "have each run's result and log artifacts land in predictable, non-clobbering locations."
- **Outcome:** each run produces its own timestamped or auto-named files without clobbering previous runs; result and log files are discoverable under the working directory.
- **Capability:** configurable output paths (`CP-001`).
- **Satisfies:** `REQ-014`.
