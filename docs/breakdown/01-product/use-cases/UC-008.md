# UC-008: Analyze Full JSON Logs After a Run

- **Actor:** developer with a completed run and JSON logging enabled.
- **Goal:** "inspect the full structured JSON log after a run to search, filter, and correlate detailed runtime events."
- **Outcome:** full machine-readable logs are available for analysis; the log archive can be searched and correlated without parsing free-form text.
- **Capability:** JSON logging tier (`CP-001`).
- **Satisfies:** `REQ-006`.
