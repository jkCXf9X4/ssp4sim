# UC-025: Run Concurrent Simulations for Parameter Sweeps

- **Actor:** user running a parameter sweep or Monte Carlo batch.
- **Goal:** "run multiple simulations concurrently as separate processes with per-run result artifacts that do not collide."
- **Outcome:** concurrent runs complete without write-lock contention or file-level append races; each run has an independent, queryable result database.
- **Capability:** local database recording (`CP-001`).
- **Strain:** safe concurrency requires per-simulation SQLite WAL auto-naming; shared-file SQLite and CSV are unsafe for concurrent writers (`REQ-005`).
- **Satisfies:** `REQ-005`, `REQ-014`.
