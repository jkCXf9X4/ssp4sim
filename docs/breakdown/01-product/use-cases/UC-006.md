# UC-006: Ingest Results into a Remote Database

- **Actor:** user with multiple simulation producers and a remote result database.
- **Goal:** "send simulation results to a remote database so runs from multiple machines land in one shared store."
- **Outcome:** results are available in a shared database; multiple producers contribute to the same history; central dashboards and comparison jobs need no local artifact access.
- **Capability:** remote database ingestion (`CP-001`).
- **Status:** not implemented in current releases; current releases produce file-based CSV and local database artifacts only.
- **Strain:** requires a new result sink, configuration schema, dependency decision, and operational contract.
