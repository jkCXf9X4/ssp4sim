# UC-012: Adjust Simulation Speed

- **Actor:** user with a running simulation.
- **Goal:** "set how fast or slow the simulation progresses relative to wall-clock time."
- **Outcome:** the simulation runs at the requested speed factor; speed affects only wall-clock timing, never simulation results.
- **Capability:** real-time pacing (`CP-001`).
- **Status:** dynamic speed adjustment planned, not yet implemented (`IMP-037`); current releases offer a binary real-time toggle (`REQ-011`).
