# UC-001: Run a Co-Simulation from an SSP Archive

- **Actor:** user with an SSP 1.0 archive, valid FMI 2.0 co-simulation FMUs, and a configuration file.
- **Goal:** "run a complete co-simulation from an SSP archive."
- **Outcome:** simulation completes without errors; results are written to the local database artifact and optional CSV export; all FMU instances are cleaned up.
- **Capability:** loads the SSP, co-simulates, and records results (`CP-001`).
- **Satisfies:** `REQ-001`, `REQ-002`, `REQ-004`, `REQ-005`.
