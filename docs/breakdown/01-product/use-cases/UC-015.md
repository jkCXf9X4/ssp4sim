# UC-015: Inject a Ramp/Linear Variable Signal During Simulation

- **Actor:** user with a running simulation and slope (k) and intercept (m) values.
- **Goal:** "inject a ramp signal of the form kx + m on a variable, immediately or at a scheduled future simulation time."
- **Outcome:** the target variable follows the linear trajectory for each subsequent timestep; the simulation continues without interruption.
- **Capability:** variable injection and scheduling (`CP-001`).
- **Status:** planned; the interface is not yet defined.
- **Strain:** whether the injected signal applies to the output side or the input side depends on the connection's propagation characteristics.
