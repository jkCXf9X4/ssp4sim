# UC-011: Pause, Resume, and Stop a Simulation

- **Actor:** user controlling a running simulation.
- **Goal:** "pause, resume, or stop the running simulation to control execution interactively."
- **Outcome:** pause suspends execution at a timestep boundary preserving simulation time and state; resume continues from the paused time; stop terminates, preserving results up to the last completed timestep and cleaning up FMU resources.
- **Capability:** interactive lifecycle control (`CP-001`).
- **Status:** planned, not yet implemented (`IMP-037`).
