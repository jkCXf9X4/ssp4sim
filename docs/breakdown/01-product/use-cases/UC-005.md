# UC-005: Query Local Result Database for Viewer and Run Comparison

- **Actor:** user or viewer/comparison tool opening a produced database file.
- **Goal:** "record a run to a local database so I can query typed time-series data without repeatedly parsing CSV."
- **Outcome:** the local database artifact is available in the working directory; result data is queryable without scanning a full CSV file; multiple runs are compared through separate per-simulation database files.
- **Capability:** local database recording (`CP-001`).
- **Strain:** only per-simulation SQLite WAL supports concurrent writers; CSV and shared-file SQLite are unsafe (`REQ-005`).
- **Satisfies:** `REQ-005`.
