# REQ-002: FMI 2.0 Co-Simulation Model Lifecycle

The engine MUST instantiate, step, and terminate FMI 2.0 co-simulation FMUs through the complete lifecycle.

- **Model description:** FMU model description XML is parsed.
- **Shared library:** FMU shared library is loaded through the FMU adapter.
- **Lifecycle:** instantiate, init, step, terminate, free execute correctly.
- **Step failure:** proper cleanup without calling terminate after a failed step.
- **Use case:** `UC-001`.
