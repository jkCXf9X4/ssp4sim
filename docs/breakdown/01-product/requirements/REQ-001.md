# REQ-001: SSP 1.0 Archive Loading

The engine MUST load and parse SSP 1.0 archives and unpacked SSP directories.

- **Archive:** `.ssp` zip archive files load.
- **Directory:** unpacked SSP directories load.
- **Parsing:** SSD XML and SSV/SSM parameter files are parsed (`REQ-015`).
- **FMU binaries:** located and referenced within the SSP (`REQ-002`).
- **Use case:** `UC-001`.
