# REQ-012: Configurable Recording Behavior

The engine MUST support configurable recording behavior: recording input signals alongside outputs, blocking producers when the recorder queue is full, and logging initial start values.

- **Inputs:** input variables are recorded to the configured sinks when input recording is enabled; defaults to off.
- **Backpressure:** the producer blocks when the recorder queue is full when waiting is enabled; defaults to off.
- **Start values:** initial start values are written to the start-values log file in the working directory.
- **Input buffer limit:** input recording uses a fixed-size buffer (10 slots); at the default recording interval, runs longer than 10 steps can overflow and silently drop input events — use backpressure or a larger interval to avoid loss.
- **Use case:** `UC-020`.
