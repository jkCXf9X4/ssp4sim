# REQ-010: Execution Strategy Variants and Tuning

The engine MUST support the documented execution strategy variants and tuning knobs: Gauss-Jacobi serial and parallel (TBB, spin-wait, futures), Gauss-Seidel serial and parallel, loop-aware execution, and custom delay-oriented executors. Thread-pool size, forward-derivative forwarding, and sub-step size MUST be configurable.

- **Method selection:** the executor method selects jacobi, seidel, custom_delay, custom_delay_partial, or la2 (legacy alias loop_aware); unknown methods are rejected.
- **Gauss-Jacobi:** parallel variant selected via configuration; method picks TBB, spin-wait, or futures.
- **Gauss-Seidel:** parallel variant selected via configuration.
- **Thread pool:** `simulation.executor.thread_pool_workers` controls the parallel worker pool size.
- **Derivatives:** `simulation.executor.forward_derivatives` toggles derivative forwarding to connected models.
- **Sub-step:** `simulation.executor.sub_step` allows a sub-step smaller than the configured timestep for delay-oriented execution.
- **Use cases:** `UC-002`, `UC-019`.
