# REQ-009: Multiple Embedding API Surfaces

The engine MUST expose simulation through three embedding surfaces: the CLI application, a C API, and Python bindings. All surfaces drive the same init-then-simulate lifecycle against the same JSON configuration.

- **CLI:** performs init and simulate, exits with a status code; a version flag prints the version.
- **C API:** exposes create, init, simulate, destroy, and last-error retrieval.
- **Python:** `Simulator` exposes a config-path constructor, `init()`, and `simulate()`.
- **Consistency:** all surfaces execute the identical init-to-simulate lifecycle against the same configuration.
- **Use cases:** `UC-003`, `UC-017`.
