# REQ-006: User-Configurable Local Logging Levels and Sinks

The engine MUST provide configurable local logging with multiple levels and sink types.

- **Sinks:** terminal, file, JSON, and cutelog; log level configurable per sink.
- **Levels:** TRACE_L2, TRACE_L1, DEBUG, INFO, WARNING, ERROR, CRITICAL.
- **Hot-path:** hot-path logging can be compiled out with zero runtime overhead (`INFO-008`).
- **Concurrency:** log sinks operate concurrently.
- **FMU logging:** FMU callback messages are forwarded to the configured sinks (`UC-024`).
- **Degradation:** the cutelog TCP sink degrades gracefully — when the listener is unavailable, a warning is logged and the run continues without that sink.
- **Use cases:** `UC-007`, `UC-008`, `UC-009`, `UC-024`.
