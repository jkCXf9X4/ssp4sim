# REQ-013: Automatic Analysis and Execution Graph Construction

The engine MUST automatically construct the simulation graph from the SSP without manual ordering configuration: parse the SSP into an analysis form, resolve model connections and signal-flow direction, and derive the execution graph dependencies.

- **Analysis model:** the SSP is parsed into an analysis system model (components, connectors, connections) without manual input.
- **Execution edges:** model-to-model execution edges are derived automatically from resolved connections.
- **Connections:** zero-delay connections are treated as feed-through edges; delay-bearing connections use delayed data-access modes.
- **Loops:** loop-aware execution detects cycles (Tarjan SCC), builds the SCC DAG, and topologically orders execution.
- **Start values:** SSV/SSM start values and parameters are applied to connectors before initialization (`REQ-015`).
- **Use case:** `UC-023`.
