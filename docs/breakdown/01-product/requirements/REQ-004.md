# REQ-004: CSV Output with Configurable Sample Interval

The engine MUST support CSV export with a configurable sample interval.

- **Enablement:** CSV output is produced when CSV recording is enabled.
- **Interval:** recording interval is configurable.
- **Coalescing:** CSV rows are coalesced by timestamp across storages.
- **Output:** written to the configured working directory (`REQ-014`).
- **Use case:** `UC-004`.
