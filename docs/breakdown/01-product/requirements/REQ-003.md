# REQ-003: Configurable Execution Strategy

The engine MUST support selecting the execution strategy (Gauss-Jacobi, Gauss-Seidel) at runtime through configuration.

- **Selection:** the executor method configuration selects the strategy.
- **Gauss-Jacobi:** parallel and serial variants (`REQ-010`).
- **Gauss-Seidel:** parallel and serial variants (`REQ-010`).
- **Custom:** delay-oriented executors are available (`REQ-010`).
- **Use case:** `UC-002`.
