# REQ-011: Realtime Wall-Clock Pacing

The engine MUST support pacing simulation execution to wall-clock time so that simulation time advances in sync with real time.

- **Pacing:** realtime pacing paces each timestep with a wall-clock reference.
- **Default:** pacing is disabled by default, running as fast as possible.
- **Results unaffected:** pacing affects only timing, not simulation results.
- **Not real-time:** pacing provides no hard real-time guarantee (`CON-001`).
- **Use case:** `UC-018`.
