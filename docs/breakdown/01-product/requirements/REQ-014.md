# REQ-014: Configurable Output Paths with Timestamped Artifacts

The engine MUST anchor default output artifact locations to the configured working directory and MUST support the `[TIME]` substitution in output path strings (CSV, SQLite, and log files), replacing it with the current timestamp at configuration load.

- **Working directory:** anchors default paths for CSV, SQLite, log, and start-value outputs; created if missing.
- **Timestamp substitution:** the literal `[TIME]` in CSV, SQLite, and log file paths is replaced with the current timestamp string.
- **Auto-naming:** when the SQLite file path is absent, a per-run file `{epoch_seconds}_{session_uuid}.sqlite` is produced in the working directory.
- **Precedence:** explicit output paths take precedence over working-directory defaults.
- **Use case:** `UC-022`.
