# REQ-007: Distributed Observability via OpenTelemetry

The engine MUST provide a distributed observability export path using OpenTelemetry for simulations that span multiple processes or services.

- **Trace emission:** simulation runs can emit OpenTelemetry trace data for distributed execution paths.
- **Propagation:** trace context can be propagated across simulation boundaries.
- **Metadata:** run id, scenario, model, and storage identity can be attached to traces.
- **Independence:** distributed observability can be enabled or disabled independently of local log sinks.
- **Status:** not yet implemented (`IMP-031`).
- **Use case:** `UC-010`.
