# REQ-005: Local Database Output with Per-Storage Tables

The engine MUST support recording simulation results to a local database with per-storage tables.

- **Enablement:** local database output is produced when SQLite recording is enabled.
- **Per-storage tables:** each signal storage area creates a separate table.
- **Output:** written to the configured working directory (`REQ-014`).
- **Alongside CSV:** local database recording runs alongside CSV export.
- **File mode:** one file per run by default (`{epoch_seconds}_{uuid}.sqlite`), or appends to a shared file when explicitly configured (sequential-only mode).
- **Concurrent writers:** only per-simulation-file SQLite WAL is safe for parallel execution; no other local backend guarantees safe concurrent multi-writer access.
  - **CSV:** file-level append race; unsafe.
  - **Shared-file SQLite WAL:** write lock serializes across tables; unsafe.
- **Use cases:** `UC-005`, `UC-025`.
