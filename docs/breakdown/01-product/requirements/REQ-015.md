# REQ-015: SSP Parameter and Start-Value Application

The engine MUST apply the SSP's parameterization to the simulation: parse system and component parameter bindings from SSV/SSM files or inline values, and apply parameter and connector start values to the FMUs before initialization.

- **Bindings:** parameter bindings (SSV values, SSM mappings, or inline) are parsed and resolved per the SSP standard.
- **Matching:** parameter values are matched to connectors via post-order traversal and dotted-path suffix matching.
- **Start values:** connector start values from the FMU model description contribute initial values.
- **Application:** applied start values are written to parameters and inputs at initialization and logged to the start-values artifact (`REQ-012`).
- **Use case:** `UC-021`.
