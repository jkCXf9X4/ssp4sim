# Users

SSP4SIM serves three user groups.

- **Strategy developers:** need a compact, controllable engine to experiment with execution strategies (Gauss-Jacobi, Gauss-Seidel) and validate SSP workflow assumptions without a full simulation environment.
- **Researchers:** need a minimal, self-contained codebase, buildable from source and deterministic across environments, for reproducible research with SSP 1.0 archives and FMI 2.0 co-simulation FMUs.
- **Engineers:** need an embeddable engine with C++23 library API, C API, and Python bindings that fits existing toolchains without a heavyweight runtime (`REQ-009`).
