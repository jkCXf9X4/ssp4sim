# Constraints

SSP4SIM operates within these fixed boundaries.

- **Platform:** Linux only; Ubuntu 22.04 primary target, x86_64.
- **FMI scope:** FMI 2.0 co-simulation only; no model exchange support.
- **SSP scope:** SSP 1.0 archives only.
- **Maturity:** experimental, not production-grade; no SLAs, no formal support.
- **Interface:** no GUI, dashboard, or web interface.
- **Platform support:** no Windows or macOS support planned.
- **Recording:** file-based CSV and local database artifacts only; no streaming or remote database output.
