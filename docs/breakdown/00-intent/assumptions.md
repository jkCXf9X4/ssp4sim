# Assumptions

SSP4SIM depends on these conditions holding.

- **SSP compliance:** archives conform to the SSP 1.0 standard.
- **FMU compliance:** FMUs provide valid FMI 2.0 model descriptions.
- **Toolchain:** host has a C++23 toolchain for source builds.
- **Determinism:** simulation is deterministic given the same SSP, configuration, and timing parameters.
- **Familiarity:** users are familiar with SSP, FMI, and co-simulation concepts.
