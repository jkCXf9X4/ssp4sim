# Purpose

SSP4SIM is a C++23 library and application for simulating SSP (System Structure and Parameterization) archives.

- **Goal:** small experimental simulation engine for developing and testing simulation strategies.
- **Path:** direct route from SSP input to an executable run.
- **Surface:** intentionally narrow runtime.
- **Embedding:** fits C++ and Python workflows without a large external runtime.
- **Codebase:** compact and understandable.
