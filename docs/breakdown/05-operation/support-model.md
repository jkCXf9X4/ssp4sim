# Support Model

No formal support model — SSP4SIM is an experimental, single-developer project (`CON-001`).

- **Issue tracking:**
  - All issues — bugs, feature requests, and questions — are tracked via GitHub Issues.
  - Bug reports include a minimal reproduction case, config file, log output, and SSP archive path.
- **Contribution:**
  - Pull requests are welcome.
  - Follow the development conventions and include tests with changes.
  - Contributing guidance lives in the project readme.
- **Expectations:**
  - No SLAs or response-time commitments.
  - Best-effort maintainer response.
  - Community contributions are encouraged.
